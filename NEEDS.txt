## 🚀 Setup Instructions for Your Friend (Windows)

### Step 1: Install Python 3.12.0 (not any other version!)
- Run the included `python-3.12.0-amd64.exe`
- **⚠️ CRITICAL:** Check the box **"Add Python 3.12 to PATH"** before clicking Install
- Choose "Install Now"

Why exactly 3.12? Because your `.whl` file is `cp312` — it only works with Python 3.12. Python 3.11 or 3.13 will refuse to install it.

### Step 2: Verify Python works
Open a **new** Command Prompt (PowerShell won't have PATH updated in old windows), then:
```cmd
python --version
```
Should print: `Python 3.12.0`

### Step 3: Open terminal in the project folder
- Open File Explorer → navigate to the `SmartAttendance` folder
- Click the address bar, type `cmd`, press Enter
  (This opens Command Prompt inside that folder directly)

### Step 4: Create a virtual environment (strongly recommended)
```cmd
python -m venv venv
venv\Scripts\activate
```
You'll see `(venv)` appear at the start of the prompt.

### Step 5: Install dependencies **in this exact order**
```cmd
python -m pip install --upgrade pip
pip install numpy==1.26.4
pip install dlib-19.24.99-cp312-cp312-win_amd64.whl
pip install face_recognition
pip install streamlit pandas opencv-python scipy plotly
```

**Order matters here:**
1. `numpy==1.26.4` first — your main.py has a hard check that refuses to start on numpy 2.x, and `face_recognition` was compiled against numpy 1.x
2. `dlib` from the local `.whl` — skips the C++ compilation nightmare entirely
3. `face_recognition` — now installs cleanly because its dependency (dlib) is already satisfied
4. Everything else

### Step 6: Run the app
```cmd
streamlit run main.py
```
The browser opens automatically at `http://localhost:8501`.

## ⚠️ Common Failure Points & Fixes

| Error | Cause | Fix |
|---|---|---|
| `ERROR: dlib-19.24.99-cp312... is not a supported wheel on this platform` | Python version isn't 3.12 | Uninstall other Python versions, reinstall 3.12.0 |
| `FATAL SYSTEM ERROR: Incompatible Numpy version` | numpy 2.x got installed | `pip uninstall numpy -y` then `pip install numpy==1.26.4` |
| Camera doesn't open / black screen | Another app (Zoom, Teams, Chrome) is using it | Close those apps |
| `ModuleNotFoundError: No module named 'face_recognition'` | Wrong environment active | Re-run `venv\Scripts\activate` before `streamlit run` |
| Webcam permission denied | Windows privacy settings | Settings → Privacy → Camera → allow desktop apps |
| Login fails with any credentials | `data/user_credentials.csv` wasn't copied | Make sure the full `data/` folder was zipped |
